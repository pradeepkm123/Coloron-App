📡 CAPTURE STEPS
1. Start Wireshark → Select WiFi adapter → Click shark fin
2. Open SuperLivePlus → Connect to camera
3. Press & HOLD talk button → Speak for 10 seconds
4. Release → Wait 3 sec → Talk again for 5 sec
5. Stop Wireshark (red square) → Save as .pcapng

🔍 FILTER IN WIRESHARK
Type in filter box:
  ip.addr == 192.168.1.XXX
(Replace XXX with your camera IP)

🎯 WHAT TO LOOK FOR
✓ UDP packets (not TCP)
✓ Packets TO camera (Destination = camera IP)
✓ Size around 160-200 bytes
✓ LOTS of packets in a row (when you spoke)
✓ Port number (usually 9000, 8000, or 6666)

💡 WIRESHARK TIPS
• Right-click packet → Follow → UDP Stream
• View → Expand All (to see all packet details)
• Edit → Find Packet (to search)
• Statistics → Conversations (to see all IPs)

🆘 COMMON ISSUES
"Too many packets"
  → Use filter: ip.addr == [CAMERA_IP]

"Can't find audio"
  → Look for UDP packets around 170 bytes
  → Look during the time you were talking

"Don't know camera IP"
  → Try each IP from the list above
  → The one with lots of traffic is your camera
